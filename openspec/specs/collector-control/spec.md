# collector-control Specification

## Purpose

Управление сборщиком daylog из приложения: запись дня включается и выключается одной кнопкой, без отдельной вкладки терминала. В любой момент работает не больше одного сборщика на каталог данных.

## Requirements

### Requirement: Один сборщик на каталог данных

`daylog.py run` SHALL на всё время работы держать эксклюзивную блокировку на `collector.lock` в каталоге данных и хранить в этом файле свой PID. Сборщик считается запущенным тогда и только тогда, когда блокировка удерживается.

#### Scenario: Второй сборщик

- **WHEN** `daylog.py run` запускают, пока другой сборщик работает с тем же каталогом данных
- **THEN** второй процесс завершается с ненулевым кодом и сообщением, что сборщик уже запущен, с его PID, и не снимает ни одного кадра

#### Scenario: Сборщик упал

- **WHEN** сборщик завершился аварийно и `collector.lock` остался на диске
- **THEN** сборщик считается не запущенным, и следующий запуск стартует без ручной очистки

### Requirement: Запуск записи из приложения

Приложение SHALL по кнопке запуска стартовать сборщик `daylog.py run` и показывать, что запись идёт. Вывод сборщика SHALL сохраняться в `collector.log` в каталоге данных.

#### Scenario: Запуск

- **WHEN** сборщик не запущен и пользователь нажимает кнопку запуска
- **THEN** сборщик стартует, кнопка превращается в кнопку остановки, индикатор показывает «запись идёт», и с ближайшей границы минуты в открытом сегодняшнем дне появляются новые минуты

#### Scenario: Нет разрешения на запись экрана

- **WHEN** пользователь нажимает кнопку запуска, а у приложения нет разрешения Screen Recording
- **THEN** приложение показывает, что нужно разрешение, с кнопкой, открывающей нужный раздел System Settings, и остаётся в состоянии «запись не идёт»

#### Scenario: Сборщик не стартовал по другой причине

- **WHEN** сборщик завершается сразу после запуска (не найден `python3`, ошибка в скрипте)
- **THEN** приложение показывает ошибку с концом вывода сборщика и остаётся в состоянии «запись не идёт»

#### Scenario: Сборщик уже запущен из терминала

- **WHEN** приложение открыто, а сборщик запущен командой `daylog.py run` в терминале
- **THEN** приложение показывает «запись идёт» и кнопку остановки, второй сборщик не запускается

### Requirement: Остановка записи из приложения

Приложение SHALL по кнопке остановки завершать работающий сборщик, кем бы он ни был запущен, и показывать, что запись не идёт.

#### Scenario: Остановка

- **WHEN** запись идёт и пользователь нажимает кнопку остановки
- **THEN** сборщик завершается, новые кадры не снимаются, кнопка снова становится кнопкой запуска

#### Scenario: Сборщик не завершился

- **WHEN** после нажатия остановки сборщик не завершился за 5 секунд
- **THEN** приложение показывает ошибку и продолжает показывать «запись идёт»

### Requirement: Актуальное состояние записи

Приложение SHALL показывать состояние записи по факту удержания блокировки и обновлять его без действий пользователя не позже чем через 30 секунд после изменения, пока окно видимо.

#### Scenario: Сборщик упал во время записи

- **WHEN** запись идёт и процесс сборщика аварийно завершается
- **THEN** в течение 30 секунд приложение показывает «запись не идёт»

### Requirement: Запись при закрытом окне

Закрытие окна MUST NOT останавливать запись: приложение SHALL оставаться запущенным, а окно — открываться снова по клику на иконку в Dock. Выход из приложения SHALL останавливать сборщик, запущенный этим приложением.

#### Scenario: Закрытие окна

- **WHEN** запись идёт и пользователь закрывает окно
- **THEN** сборщик продолжает работать, клик по иконке в Dock возвращает окно с состоянием «запись идёт»

#### Scenario: Выход из приложения

- **WHEN** запись запущена из приложения и пользователь выходит из него (Cmd+Q)
- **THEN** сборщик завершается

### Requirement: Возобновление записи при запуске

Приложение SHALL при запуске само стартовать сборщик, если при прошлом выходе запись шла и не была остановлена кнопкой.

#### Scenario: Вышел во время записи

- **WHEN** пользователь вышел из приложения, не останавливая запись, и запускает его снова
- **THEN** запись стартует без нажатия кнопки

#### Scenario: Остановил кнопкой

- **WHEN** пользователь остановил запись кнопкой, вышел и запускает приложение снова
- **THEN** запись не стартует, пока он не нажмёт кнопку запуска
