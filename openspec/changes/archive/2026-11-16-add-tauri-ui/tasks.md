# Tasks

Перед началом прочитать `proposal.md`, `design.md` и четыре файла в `specs/`. Каталог с настоящими данными `~/.local/share/daylog` не менять: для проверок использовать `DAYLOG_DIR=<временный каталог>` с копией дня. Работающий у пользователя сборщик (`daylog.py run` в его терминале) не останавливать и настоящую запись экрана не запускать: запуск и остановку проверять подставным скриптом через `DAYLOG_SCRIPT` и временным `DAYLOG_DIR`. Настоящую запись включает пользователь, задача 8.4.
