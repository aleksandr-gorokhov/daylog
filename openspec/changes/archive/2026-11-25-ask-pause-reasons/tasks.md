# Tasks

Перед началом прочитать `proposal.md`, `design.md` и файлы в `specs/`. Каталог с настоящими данными `~/.local/share/daylog` не менять: для проверок использовать `DAYLOG_DIR=<временный каталог>`. Работающий у пользователя сборщик не останавливать. Вызовов LLM в этом изменении нет.

Минуты «нет ввода» определяет спека `minute-capture`; в `daylog.py` это `since_input` и `pending`. Эти функции и текст README о паузах не менять: в `daylog.py` добавляется только команда `pause`.

Для проверок в `pnpm tauri dev` кроме `DAYLOG_DIR` задавать `DAYLOG_SCRIPT=<обёртка>`. Обёртка передаёт команду `pause` настоящему `daylog.py`, а на `run` только держит блокировку `collector.lock` и ничего не снимает. Без неё приложение при запуске возобновит запись (`resume_collector` читает общий `state.json`) и начнёт настоящую съёмку экрана и вызовы LLM во временный каталог.

Тестовый день для ручных проверок: во временном `DAYLOG_DIR` каталог с сегодняшней датой, в `captures.jsonl` несколько обычных минут с малым `idle_sec`, затем два отрезка без ввода, разделённые обычными минутами; последний отрезок стоит в конце файла. В каждом отрезке `idle_sec` растёт на 60 от минуты к минуте и доходит до 300 и больше, у строк от порога есть `"idle": true`. В `minutes.jsonl` описаны минуты перед первым отрезком.
