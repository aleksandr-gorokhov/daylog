# Spec Delta

## MODIFIED Requirements

### Requirement: Только чтение

Приложение MUST NOT само изменять и удалять файлы дней в каталоге данных. Данные меняет только `daylog.py`, который приложение запускает для записи, сборки отчёта, доразметки категорий и записи причин пауз.

#### Scenario: Просмотр дня

- **WHEN** пользователь открывает и листает любые дни
- **THEN** ни один файл в каталоге данных не меняется

#### Scenario: Запись причины паузы

- **WHEN** пользователь сохраняет причину паузы в окне с вопросом или в списке пауз
- **THEN** приложение запускает `daylog.py pause`, и в каталоге дня меняется только `pauses.jsonl`
